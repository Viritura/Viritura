Viritura sfizz browser proof of concept third-party notices

This standalone prototype builds sfizz WebAssembly locally from pinned source for
experimentation. The generated bundle is ignored by Git and is not redistributed
with the prototype source:

  Source repository: https://github.com/sfztools/sfizz-webaudio
  Source commit: 41f08e6974c48f3f424509d37cd78631596cacfb
  Engine: https://github.com/paulfd/sfizz
  Engine commit: 0b3aaa8cedb0d732fb15820db7eda2c841657d2d
  Emscripten SDK: 3.1.31
  Emscripten SDK repository commit: 974d5c096bd56e42045d052a47b28198ce75e2a8
  Generated artifact SHA-256: B5C95D2E396D23F1B7F6176C9564F41D88793551DD534A402C69269E2FD3388B

vendor/build-sfizz.ps1 fetches only the required pinned submodules and applies the checked-in
source patches under vendor/patches. The wrapper bootstrap instrument is removed, load returns
sfizz's success value, and loadAtPath accepts an explicit virtual SFZ path. The engine patch
preserves FileData::preloadCallCount in move construction and move assignment so Abseil map
growth cannot discard live preloaded samples during reload. FS, _malloc, and _free are exported
with Emscripten linker flags; generated JavaScript is not text-patched.

Required sfizz submodules:

  Abseil: 215105818dfde3174fe799600bb0f3cae233d0bf
  filesystem: 614bbe87b80435d87ab8791564370e0c1d13627d
  SIMDe: 98075d0593f539762125dbb215d95e782a6ae344
  dr_libs: cac1785cee4abb455817b43d5dee33b49d61be2f
  libaiff: 78864a4a2e769e426be8cfd78ae7f5f72e236c33
  stb_vorbis: fc0bd698b26888da0a632da33f4c49b90763e69b

The launcher verifies the local artifact hash and invokes the source build if missing.
Browser playback then uses only localhost assets and user-selected files. No samples
are downloaded or uploaded.
