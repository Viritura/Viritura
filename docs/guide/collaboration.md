# Collaboration

**Live** collaboration lets people edit the same document together through a
shared capability link.

## Start a live session

Open a versioned project, choose the Live button near the bottom of the Activity
Bar, and select **Start live session**. Viritura creates a capability link and
copies it when clipboard access is available.

Anyone with the link can join without creating an account. Share it only with
people who should be able to edit the document.

## During collaboration

The Live panel lists participants and shows whether the session is active.
Collaborator presence, cursors, selections, and document edits update in real
time. Changes still use the same MNX document model as local editing.

The host page anchors the live session. Closing it ends the session for
everyone. Choose **Leave** when you are finished and remove the room link from
the address bar before sharing an unrelated browser URL.

For project history and inspecting revisions, see
[Viewing & Review](/docs/viewing-and-review#review-version-history). To connect
an external client to an open document, see [MCP](/docs/mcp).
