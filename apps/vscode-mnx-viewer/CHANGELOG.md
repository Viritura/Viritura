# Change Log

## 0.1.0 - 2026-08-31

- Updated the bundled Viritura Rust/WASM engraving engine and shared score viewer.
- Improved natural spacing for sparse excerpts and physical page geometry.
- Added zoom, fit-to-width, and Ctrl+wheel zoom controls.
- Added page, horizontal, spread, and horizontal spread arrangements.
- Added score selection for MNX documents containing multiple scores.
- Improved horizon and large-score rendering performance.
- Improved preview loading and error states while preserving live refresh as MNX source changes.
- Continued to bundle the engraving engine, Bravura, and Libertinus fonts for offline rendering.
