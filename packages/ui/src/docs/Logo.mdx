# Logo

Viritura's production identity combines the **Folio Display** wordmark
with the **Contained Versal Keyline** mark.

The wordmark is outlined from Libertinus Serif small caps, so it renders
consistently without requiring an installed font. The mark centers that
same V with a deliberate optical inset inside a deep-viridian square and
contains the field with a fine warm-paper keyline.

## Usage

Use the lockup where there is room for the name: start center, splash,
marketing pages, and Storybook brand surfaces.

Use the mark alone where space is constrained: favicon, app icon, compact
launcher surfaces, and any future mobile home-screen icon.

The mark and wordmark are exported from `@viritura/ui` as
`VirituraMark`, `VirituraWordmark`, and `VirituraLogo`.

The wordmark inherits `currentColor`. The mark keeps its production
colors through `--viritura-brand` (`#215e4e`) and
`--viritura-brand-ink` (`#e7f3ee`); the border uses
`--viritura-brand-keyline` (`#dceee7`). These fall back to the shared
`--brand*` tokens so the crop remains consistent on every surface.
