# Radii & Spacing

## Border-radius scale

Six steps from hairline to pill. Always reference the token — never
hardcode `border-radius: 8px;`.

<div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(140px, 1fr))", gap: 16, marginTop: 20 }}>
  {[
    { token: "--radius-xs", px: "3px", use: "Hairline corners (badges, tiny chips)" },
    { token: "--radius-sm", px: "4px", use: "Small chips, dense pills" },
    { token: "--radius-md", px: "6px", use: "Buttons, inputs" },
    { token: "--radius-lg", px: "8px", use: "Cards, panels, popovers" },
    { token: "--radius-xl", px: "12px", use: "Dialogs, large containers" },
    { token: "--radius-pill", px: "999px", use: "Pill buttons, toggle chips" },
  ].map(({ token, px, use }) => (
    <div key={token} style={{ display: "flex", flexDirection: "column", alignItems: "center", gap: 8 }}>
      <div
        style={{
          width: 100,
          height: 60,
          borderRadius: `var(${token})`,
          background: "rgba(var(--accent-rgb), 0.18)",
          border: "1px solid rgba(var(--accent-rgb), 0.45)",
        }}
      />
      <div style={{ textAlign: "center" }}>
        <div style={{ fontFamily: "monospace", fontSize: 11, color: "var(--text)" }}>{token}</div>

### Radius decision guide

> **Container holds other containers?** → `--radius-xl` (12px) — dialog, large card
>
> **Container holds content directly?** → `--radius-lg` (8px) — panel, popover
>
> **Interactive control?** → `--radius-md` (6px) — button, input, select
>
> **Tiny indicator?** → `--radius-xs` / `--radius-sm` (3–4px) — badge
>
> **Pure pill shape?** → `--radius-pill` — toggle chips, mode tabs

### Concentric radii (nested corners)

When a rounded child sits inside a rounded parent with consistent padding
on all sides, **the two arcs should share a center**. Otherwise the
visible gap between them pinches at the corners (arcs converge) or
balloons (arcs diverge), and the eye reads the child as "off."

> **`childRadius = parentRadius − padding`**
>
> Equivalently, when sizing a parent around a known child:
> **`parentRadius = childRadius + padding`**

If the formula produces ≤ 0, the child should be **square** (`0`) — a
sharp child inside a rounded parent reads cleanly as long as the padding
covers the full radius.

<div style={{ display: "grid", gridTemplateColumns: "repeat(2, 1fr)", gap: 16, marginTop: 16 }}>
  {[
    {
      label: "Concentric (parent 20, pad 8 → child 12)",
      good: true,
      parent: 20,
      pad: 8,
      child: 12,
    },
    {
      label: "Broken (parent 20, pad 8, child 2) — arcs don't agree",
      good: false,
      parent: 20,
      pad: 8,
      child: 2,
    },
  ].map(({ label, good, parent, pad, child }) => (
    <div key={label} style={{ display: "flex", flexDirection: "column", gap: 8 }}>
      <div
        style={{
          padding: pad,
          borderRadius: parent,
          background: "rgba(var(--accent-rgb), 0.18)",
          border: "1px solid rgba(var(--accent-rgb), 0.55)",
        }}
      >
        <div
          style={{
            height: 80,
            borderRadius: child,
            background: "var(--surface)",
            border: "1px solid var(--border)",
          }}
        />
      </div>
      <div style={{ fontSize: 11, color: good ? "var(--accent)" : "var(--error)", fontFamily: "monospace" }}>
        {good ? "✓ " : "✗ "}
        {label}
      </div>
    </div>
  ))}
</div>

#### Common Viritura pairings

| Parent                          | Padding          | Child radius               |
| ------------------------------- | ---------------- | -------------------------- |
| Dialog (`--radius-xl`, 12)      | `0.25rem` (4px)  | `--radius-lg` (8)          |
| Card / panel (`--radius-lg`, 8) | `0.25rem` (4px)  | `--radius-sm` (4)          |
| Button (`--radius-md`, 6)       | `0.25rem` (4px)  | `--radius-xs` (2–3)        |
| Anything                        | padding ≥ radius | `0` (square child is fine) |

Pill-shaped parents (`--radius-pill`) are the exception — the child is
typically rendered against the parent edge with no inner border, so the
concentric rule collapses to "fill the parent." When a pill _does_ contain
a visibly bordered child, treat the parent radius as `height / 2` and
apply the formula.

## Spacing

Viritura uses **`rem`-based spacing** keyed off the document root font
size (16px). No dedicated `--space-*` tokens yet; use `rem` directly:

| Size      | Value | Typical use                         |
| --------- | ----- | ----------------------------------- |
| `0.25rem` | 4px   | Icon ↔ text gap, tight pill padding |
| `0.5rem`  | 8px   | Button gap, form row spacing        |
| `0.75rem` | 12px  | Card padding, header band padding   |
| `1rem`    | 16px  | Dialog body padding, section margin |
| `1.25rem` | 20px  | Dialog header padding               |
| `1.5rem`  | 24px  | Dialog content padding, page gutter |
| `2rem`    | 32px  | Large section gap                   |

### When `px` is acceptable

- Border widths (`1px`, `1.5px`)
- Box-shadow stops (already in tokens — don't author new ones inline)
- Icon pixel sizes (`size={16}` on Lucide)
- Sub-pixel adjustments for hairlines

Everywhere else, use `rem`.

## Panel & component widths

| Surface              | Width                  |
| -------------------- | ---------------------- |
| Default dialog       | 420px                  |
| Wide dialog          | 640px (max 90vw)       |
| Full dialog          | 90vw × 80vh            |
| Side panel (default) | 280px                  |
| Inspector            | 320px                  |
| Popover (default)    | 240–320px              |
| Tooltip              | content-fit, max 280px |

These are conventions, not tokens — use them as defaults, override per
component when a feature genuinely needs different proportions.

## Touch targets

Interactive controls minimum size: **32 × 32 px** for cursor input,
**44 × 44 px** for touch-primary surfaces (none yet — Viritura is
cursor-first). Smaller pill chips are acceptable within a `ToggleGroup`
because the group itself is the target zone.
