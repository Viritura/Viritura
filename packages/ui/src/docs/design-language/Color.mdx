# Color

Tokens are defined in `packages/ui/src/tokens.css` and themed via the
`[data-theme]` attribute on `<html>`.

## Themes

| Theme      | Mode                                                       | Canvas                                          |
| ---------- | ---------------------------------------------------------- | ----------------------------------------------- |
| `light`    | Default                                                    | Near-white paper                                |
| `dark`     | Inverted UI                                                | Near-black canvas, dark chrome                  |
| `midnight` | Dark chrome + inverted canvas (via CSS `filter: invert()`) | Light paper drawn, inverted to dark for display |

### When to reach for the accent

| Use it for                            | Don't use it for                              |
| ------------------------------------- | --------------------------------------------- |
| Primary action button                 | Secondary actions                             |
| Selected note / score                 | Hover state (use `--surface-hover`)           |
| Focus ring on inputs                  | Body text                                     |
| Brand wordmark                        | Danger / warning (use `--error`, `--warning`) |
| "Current mode" indicator              | Borders                                       |
| **Success / saved / confirmed** state | — (no separate success token, see below)      |

## Status

Viritura ships **only two status colors**, because only two states
demand the urgency that color provides: errors and warnings. Success is
the absence of failure and uses the brand accent — viridian is the
color of _thriving_, and a successful save is a brand moment.

**Color is never the signal.** Every status message pairs a color with
an icon and a text label (per [WCAG 1.4.1 "Use of
Color"](https://www.w3.org/WAI/WCAG21/Understanding/use-of-color.html)).
Color reinforces; the icon and the words carry the meaning.

<div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(160px, 1fr))", gap: 12, marginTop: 16 }}>
  {[
    { token: "--error", label: "Error / destructive", Icon: CircleAlert },
    { token: "--warning", label: "Warning / caution", Icon: TriangleAlert },
    { token: "--accent", label: "Success / saved (brand)", Icon: CircleCheck },
  ].map(({ token, label, Icon }) => (
    <div
      key={token}
      style={{ borderRadius: 8, border: "1px solid var(--border)", overflow: "hidden", background: "var(--surface)" }}
    >
      <div
        style={{
          height: 48,
          background: `var(${token})`,
          color: "#fff",
          display: "flex",
          alignItems: "center",
          justifyContent: "center",
        }}
      >
        <Icon size={22} strokeWidth={2.25} />
      </div>
      <div style={{ padding: "8px 10px", fontSize: 12 }}>
        <div style={{ fontFamily: "monospace", color: "var(--text)" }}>{token}</div>
        <div style={{ color: "var(--text-muted)", marginTop: 2 }}>{label}</div>
      </div>
    </div>
  ))}
</div>

## Diff overlays

Tinted backgrounds for the Review-mode diff view. **These are alpha
overlays on the brand and error palette, not separate colors** — added
and modified both tint with viridian (different α to distinguish them);
removed tints with red. The diff tree pairs each row with a `+`, `✎`, or
`−` glyph, so the shared hue between added and modified is reinforcement,
not the signal.

<div style={{ display: "grid", gridTemplateColumns: "repeat(3, 1fr)", gap: 12, marginTop: 16 }}>
  {[
    { token: "--diff-added-bg", label: "Added", derivation: "rgba(accent, .12)" },
    { token: "--diff-modified-bg", label: "Modified", derivation: "rgba(accent, .06)" },
    { token: "--diff-removed-bg", label: "Removed", derivation: "rgba(error, .10)" },
  ].map(({ token, label, derivation }) => (
    <div
      key={token}
      style={{ padding: 12, borderRadius: 8, background: `var(${token})`, border: "1px solid var(--border)" }}
    >
      <div style={{ fontFamily: "monospace", fontSize: 12, color: "var(--text)" }}>{token}</div>
      <div style={{ fontSize: 12, color: "var(--text-muted)", marginTop: 2 }}>{label}</div>
      <div style={{ fontFamily: "monospace", fontSize: 10, color: "var(--text-muted)", marginTop: 4 }}>
        {derivation}
      </div>
    </div>
  ))}
</div>
